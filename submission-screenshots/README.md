# 제출용 화면 캡처

2026-09-23에 배포된 Vercel/Render 서비스에서 캡처한 화면입니다. 실제 블로그 통계 요약과 AI 대화 내용이 포함됩니다. 서비스 접근키나 AI·Firebase 비밀키는 캡처에 없습니다.

- `01-chat-and-summary.png`: 채팅 화면과 저장된 관측값 180개, 90일 요약
- `01b-chat-answer.png`: 실제 통계를 반영한 질문과 Gemini 답변
- `02-data-edit.png`: Firestore 데이터 수정 후 갱신된 목록. 캡처용 메모 변경은 원래 값으로 되돌렸습니다.
- `03-conversation-list.png`: 이전 대화 목록과 불러오기 버튼
- `04-swagger.png`: Render에 배포된 FastAPI Swagger UI

무료 Render 인스턴스가 잠들어 있을 때에는 첫 접속이 느릴 수 있습니다. 화면 캡처는 접속 지연 시 기능과 디자인을 확인하기 위한 증빙입니다.
